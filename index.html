Install

Pick your distribution. Native packages install Apache, MariaDB and PHP automatically.

  1. Download the package from the latest release (.deb)
  2. Install it
sudo apt install ./LinuxDevStackBox_*.deb
  1. Download the package from the latest release (.pkg.tar.zst)
  2. Install it
sudo pacman -U linuxdevstackbox-*.pkg.tar.zst
  1. Download the package from the latest release (.rpm)
  2. Install it
sudo dnf install ./LinuxDevStackBox-*.rpm
  1. Install the services the AppImage does not bundle: Apache, MariaDB/MySQL, php-cgi
  2. Make it executable and run it
sudo apt install apache2 mariadb-server php-cgi php-cli php-mysql # Debian/Ubuntu
sudo pacman -S apache mariadb php php-cgi # Arch
chmod +x LinuxDevStackBox_*.AppImage && ./LinuxDevStackBox_*.AppImage

If the AppImage does not start, install FUSE (libfuse2). A blank window? Run it with WEBKIT_DISABLE_DMABUF_RENDERER=1.

After installing, open LinuxDevStackBox, start Apache and MySQL, then visit http://localhost:8080/ and http://localhost:8080/phpmyadmin/.

FAQ

Why does Apache run on port 8080?

Linux does not let normal users open ports below 1024. LinuxDevStackBox uses 8080 (HTTPS 8443) unless your system allows low ports: sudo sysctl net.ipv4.ip_unprivileged_port_start=80.

Where are my projects and data?

Projects live in ~/LinuxDevStackBox/www. Configuration, logs and databases are in ~/.local/share/linuxdevstackbox.

How do I add another PHP version?

Install it with your package manager (for example php8.4-cgi from the Ondřej PPA). LinuxDevStackBox detects it automatically.

Will it conflict with the Apache/MariaDB services of my distribution?

The app runs its own instances. If MariaDB from systemd already uses port 3306, stop it with sudo systemctl disable --now mariadb.

What is the relation to DevStackBox?

LinuxDevStackBox is a Linux port of the Windows project DevStackBox by Nomad Programmer, maintained by mamsm-dev.
