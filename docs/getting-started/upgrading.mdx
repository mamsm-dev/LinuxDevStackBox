# Upgrade LinuxDevStackBox

LinuxDevStackBox upgrades preserve user data. Configs, HTTPS certificates and `vhosts.json` live in `~/.config/linuxdevstackbox`; logs, MySQL data, backups and web projects live in `~/.local/share/linuxdevstackbox/www` and siblings. Neither directory is touched by reinstalling the app package or by uninstalling.

Because Apache, MariaDB/MySQL and PHP come from your distribution, keep them current with your normal system updates. When a database-server package upgrade is involved, back up your databases first; see [Troubleshooting](../advanced/troubleshooting) if MySQL will not start after a system update.

## Check for updates in the app

LinuxDevStackBox checks GitHub Releases for a newer version:

1. Open **Settings → Updates**.
2. Turn on **Auto-check updates** (stored in `localStorage` as `devstackbox.settings.autoCheckUpdates`).
3. When enabled, the app checks on launch (after a short delay) and every 6 hours.
4. Use **Check for updates** on the About page for a manual check.

When an update is available, the header shows an indicator and the app displays the new version with upgrade instructions for your package manager. There is no self-install on Linux. When you are already on the latest release, a manual check shows an "up to date" message.

## Upgrade with your package manager (recommended)

1. **Stop services** - stop Apache and MySQL from the dashboard or tray menu.
2. **Back up first** - use **Settings → Backup & Restore** to create a full backup. Connected projects outside `www` keep their files in their original folders; back up those folders separately because full backups do not include their contents.
3. **Download** the newer package from [GitHub Releases](https://github.com/mamsm-dev/LinuxDevStackBox/releases/latest) - or receive it through your AUR helper/repository if you installed it that way.
4. **Reinstall the package**:
   - **Arch:** `sudo pacman -U ./linuxdevstackbox-*.pkg.tar.zst`
   - **Debian/Ubuntu:** `sudo apt install ./linuxdevstackbox_*.deb`
   - **Fedora:** `sudo dnf install ./linuxdevstackbox-*.rpm`

   Reinstalling the newer package upgrades the app in place.
5. **Launch LinuxDevStackBox** - start services and confirm your sites and databases are intact.

Your user data layout:

```
~/.config/linuxdevstackbox/        Apache, MySQL, PHP configs, vhosts.json, HTTPS certificates
~/.local/share/linuxdevstackbox/
  logs/             service logs
  mysql-data/       MySQL database files
  www/              web root holding projects
  backups/          app-created backups
  phpmyadmin/       writable copy of the bundled phpMyAdmin
```

The app package is replaced by the upgrade; the config and data directories are not.

## If something goes wrong

- Services fail after upgrade → [Troubleshooting](../advanced/troubleshooting)
- Port conflicts → [Configuration](../reference/configuration) and [Environment](../advanced/environment)
- Restore from backup → **Settings → Backup & Restore**
