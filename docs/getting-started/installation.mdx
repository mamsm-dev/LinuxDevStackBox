# Install LinuxDevStackBox

LinuxDevStackBox ships as a native package per distribution family: a `.pkg.tar.zst` for Arch (and derivatives), a `.deb` for Debian (and derivatives), and an `.rpm` for Fedora (and derivatives).

Apache, MariaDB/MySQL, PHP and php-cgi are **not bundled**. They come from your distribution's packages. If a required binary is missing, the app refuses to start that service and prints the install command for your family.

## Download

Get the latest package for your distribution from [GitHub Releases](https://github.com/mamsm-dev/LinuxDevStackBox/releases/latest).

## What the packages include

| Component | Source |
| --------- | ------ |
| phpMyAdmin | Bundled with the app (writable copy in the data dir) |
| Apache | Distribution package |
| MariaDB/MySQL | Distribution package |
| PHP + php-cgi | Distribution package (minimum 8.2, single system runtime) |

## Install the distribution stack first

If Apache, MariaDB and PHP are not already installed:

- **Arch:** `sudo pacman -S apache mariadb php php-cgi`
- **Debian/Ubuntu:** `sudo apt install apache2 mariadb-server php php-cgi`
- **Fedora:** `sudo dnf install httpd mariadb-server php php-cgi`

## Install LinuxDevStackBox

1. Install the package you downloaded with your package manager:
   - **Arch:** `sudo pacman -U ./linuxdevstackbox-*.pkg.tar.zst`
   - **Debian/Ubuntu:** `sudo apt install ./linuxdevstackbox_*.deb`
   - **Fedora:** `sudo dnf install ./linuxdevstackbox-*.rpm`
2. Launch LinuxDevStackBox from your application menu.
3. Open the app and start Apache and MySQL when you need them. Services run as your logged-in user, never as root - do not run the whole app with sudo.
4. Open [http://localhost:8080/phpmyadmin](http://localhost:8080/phpmyadmin) to confirm the stack works. Apache binds `127.0.0.1` on port 8080 by default; the port is configurable in the config editor.

## Updates

LinuxDevStackBox checks GitHub releases for a newer version and tells you to upgrade the package with your package manager. There is no self-install on Linux. See [Upgrading](upgrading).

## Uninstall

- **Arch:** `sudo pacman -R linuxdevstackbox`
- **Debian/Ubuntu:** `sudo apt remove linuxdevstackbox`
- **Fedora:** `sudo dnf remove linuxdevstackbox`

Your user data is **not** removed on uninstall: configs stay in `~/.config/linuxdevstackbox` and data (including `www`, logs, databases and backups) stays in `~/.local/share/linuxdevstackbox`. Delete those folders manually if you want a complete cleanup.
