# LinuxDevStackBox - Environment Reference

**Ports, conflicts, environment variables, privilege separation, and localhost configuration.**

---

## Default Ports

| Service     | Default Port                        | Config File                       | Config Key        |
| ----------- | ----------------------------------- | --------------------------------- | ----------------- |
| Apache HTTP | 8080 (unprivileged)                 | `~/.config/linuxdevstackbox/httpd.conf` | `Listen 127.0.0.1:8080` |
| MySQL       | 3306                                | `~/.config/linuxdevstackbox/my.cnf`     | `port = 3306`     |
| HTTPS       | 443                                 | managed via the app's SSL controls | -                 |
| phpMyAdmin  | (served through Apache on port 8080) | -                                | -                 |

Apache defaults to 8080 because it runs unprivileged - no root rights are needed to serve HTTP on a high port.

---

## Binding Behavior

By default, all services bind to `127.0.0.1` (loopback) only.

This means:

- Services are accessible from your machine only
- Services are NOT exposed to your local network or internet
- This is intentional for a local dev environment

**Do NOT change bind addresses unless you know the security implications.** See [SECURITY.md](/security).

## Environment Variables

| Variable                    | Effect |
| --------------------------- | ------ |
| `LINUXDEVSTACKBOX_DATA_DIR` | Relocates both user roots together: the config root and the data root become `<dir>` and `<dir>/config` |
| `XDG_CONFIG_HOME`           | Standard XDG base directory; the config root defaults to `$XDG_CONFIG_HOME/linuxdevstackbox` (`~/.config/linuxdevstackbox`) |
| `XDG_DATA_HOME`             | Standard XDG base directory; the data root defaults to `$XDG_DATA_HOME/linuxdevstackbox` (`~/.local/share/linuxdevstackbox`) |

The data root holds `logs/`, `mysql-data/`, `www/`, `backups/`, `config-backups/`, the writable phpMyAdmin copy and the staged `cgi-bin/`. The config root holds `httpd.conf`, `my.cnf`, `php.ini`, `vhosts.json`, the `https/` material and the 0600 MySQL root credentials file.

## Privilege Separation and CLI Flags

The GUI never runs as root. Exactly two operations are elevated, each a single fixed-argument `pkexec` invocation of the app binary itself (you will see a Polkit authentication prompt):

- `--hosts-operation add|remove <domain>` - edits `/etc/hosts` for virtual hosts
- `--ca-trust-operation install|remove` - installs or removes the local CA anchor in the distribution trust store and refreshes it

Other CLI flags (no elevation):

- `--setup-local-https` - provision local HTTPS
- `--https-status` - print HTTPS status
- `--start-apache` - start Apache
- `--stop-services` - stop all managed services

Process safety: a running service counts as "ours" only when its command line references the app's generated config (`httpd.conf` / `my.cnf`). System services are never touched or stopped by LinuxDevStackBox.

## Common Port Conflicts

### Port 8080 Already in Use

**Typical culprits:**

| Service                             | How to Check                | How to Stop                      |
| ----------------------------------- | --------------------------- | -------------------------------- |
| System Apache (httpd/apache2)       | `systemctl status httpd apache2` | `sudo systemctl stop httpd apache2` |
| Another local dev stack             | `ss -ltnp`                  | Stop the other stack             |
| Any other process                   | `ss -ltnp 'sport = :8080'`  | Stop that process                |

**Fix:**

1. Find what is listening: `ss -ltnp | grep 8080`
2. Stop that service (prefer `systemctl` for system services)
3. Try starting Apache again

Or change Apache's port in the generated `httpd.conf` (or the app's port setting):

```
Listen 127.0.0.1:8081
```

Note: changing the port means the phpMyAdmin URL changes too, for example `http://localhost:8081/phpmyadmin/`.

### Port 3306 Already in Use

**Typical culprits:**

| Service                        | How to Stop                             |
| ------------------------------ | --------------------------------------- |
| System MariaDB/MySQL service   | `sudo systemctl stop mariadb` (or `mysqld`) |
| Docker MySQL container         | `docker stop <container>`               |
| Another local dev stack        | Stop the other stack                    |

**Fix:**

```bash
ss -ltnp | grep 3306
```

Or change MySQL's port in the generated `my.cnf`:

```ini
[mysqld]
port = 3307
```

Note: changing the port means you must connect phpMyAdmin to the new port.

## Firewall Behavior

Services bind to loopback only, so most desktop firewalls require no changes. If you reconfigure a service to listen on an external interface, you may need to allow the port explicitly:

- firewalld (Fedora family): `sudo firewall-cmd --add-port=8080/tcp`
- ufw (Debian family): `sudo ufw allow 8080/tcp`

Do not open these ports to untrusted networks - this is a local development stack.

## Accessing phpMyAdmin

URL: `http://localhost:8080/phpmyadmin/`

Default credentials:

- Username: `root`
- Password: (empty)

If phpMyAdmin shows "Cannot connect to MySQL server":

1. Check MySQL is running (green status in LinuxDevStackBox)
2. Check the phpMyAdmin config in the data root copy - `$cfg['Servers'][$i]['host']` should be `127.0.0.1`
3. Check MySQL port is 3306 (default)

## Localhost DNS Behavior

`localhost` resolves to `127.0.0.1` via `/etc/hosts`:

```
127.0.0.1   localhost
```

LinuxDevStackBox does NOT modify this file unless you use the virtual hosts feature. Adding or removing a virtual-host domain runs the app binary once under `pkexec` (`--hosts-operation add|remove <domain>`) and shows a Polkit prompt. Review the requested domain before accepting the prompt.

## HTTPS / SSL

Localhost SSL is available through the app's SSL controls. LinuxDevStackBox creates a local CA and localhost certificate with the system `openssl`; trusting the CA installs it into the distribution trust store via a single `pkexec` invocation (`--ca-trust-operation install`) and refreshes the store. Per-virtual-host HTTPS remains planned. See [Feature status](../feature-status) for current scope.

## Network Diagnostics

Quick commands to check port state:

```bash
# Check what is listening on port 8080
ss -ltnp 'sport = :8080'

# Check what is listening on port 3306
ss -ltnp 'sport = :3306'

# List all listening TCP ports
ss -ltn

# Find which process owns a PID
ps -p <PID> -o pid,cmd
```
